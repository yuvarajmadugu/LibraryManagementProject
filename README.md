### LibraryManagementProject
# 📚 Mini Library Management System
This is a simple Java-based Library Management System project designed to demonstrate object-oriented programming concepts such as inheritance, interfaces, and class hierarchies. The system maintains a small collection of books and magazines (up to 10 items), and supports basic user roles like students and professors.

# 🚀 Features
- Supports up to 10 library items (Books and Magazines)
- Implements inheritance:
    LibraryItem → base class for BookClass and MagazineClass
    UserClass → base class for StudentClass and ProfessorClass
- Defines and uses a BookOperations interface for core functionality
- LibraryClass implements BookOperations to manage library operations
- All classes are orchestrated through a single MainClass

# 🛠️ Technologies Used
- Java (Core Java, Object-Oriented Programming)
